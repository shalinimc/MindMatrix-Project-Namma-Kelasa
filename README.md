The Namma Kelasa application was developed as an Android-based job portal using modern mobile application development technologies integrated with Generative AI concepts. The main objective of the application is to help users search and apply for jobs easily through a simple and user-friendly mobile interface. The application was designed and developed using Android Studio with Kotlin programming language, while Firebase was used for authentication, real-time database management, and cloud storage services. The project also integrates GenAI features to provide smart recommendations, user guidance, and improved interaction within the application.

The development process included requirement analysis, UI/UX design, database integration, API connectivity, and testing of different modules. The application consists of several modules such as user registration and login, job listings, job application management, notifications, admin dashboard, and profile management. SharedPreferences were used for session handling, and REST APIs were integrated for smooth data communication between the frontend and backend systems. The use of Generative AI helped in enhancing the application by providing intelligent suggestions, improving content generation, and making the user experience more interactive and efficient.

The project development followed a structured software development approach including planning, coding, debugging, testing, and deployment phases. Different Android components such as Activities, RecyclerView, Fragments, Firebase Authentication, and Cloud Firestore were implemented to ensure better performance and scalability. The application was tested on multiple Android devices to verify responsiveness, functionality, and usability. Overall, the Namma Kelasa application demonstrates the practical implementation of Android app development integrated with GenAI technologies to create a smart and efficient employment support platform for users.
